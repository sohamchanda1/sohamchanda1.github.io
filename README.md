# Soham Chanda academic website

Static, GitHub Pages-ready academic profile site.

## Files

- `index.html`: all page content
- `assets/styles.css`: visual design

## Deploy on GitHub Pages

1. Create a repository named `sohamcha.github.io` or any other repo name.
2. Upload these files to the repository root.
3. In GitHub, go to Settings -> Pages.
4. Choose `Deploy from a branch`, branch `main`, folder `/root`.
5. Your site will be available at `https://<username>.github.io/` or `https://<username>.github.io/<repo>/`.

## Edit points

- Replace the `SC` avatar block with a photo if desired.
- Update position/title text after 2027.
- Move detailed course pages into this site later if you want to leave Google Sites entirely.
